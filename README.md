# IntraClouds - Modern Corporate Website

A clean, professional, and fully responsive single-page website for IntraClouds.

## Features
- Modern Light/Dark mode with smooth toggle
- Responsive design (mobile-first)
- Tailwind CSS + Vanilla JavaScript
- Professional UI/UX
- Fast loading & SEO friendly
